# StudyCrew website: notes for Claude Code

The user writes in Russian; reply in Russian. The site's content is Russian too.

## What this project is
A promo landing page for StudyCrew, a study app for school and university students (closed beta on Android, ages 13+).
- **Stack:** Next.js 16 App Router, React 19.
- **Deployment target:** Cloudflare Workers, using **vinext**, Cloudflare's recommended way to run Next.js on Workers (beta).
- **Static only:** `next.config.ts` sets `output: 'export'`. There is no backend: no databases, KV, caches or server routes. Keep it that way.
- **Self-contained:** the app screens on the page are React/CSS concept mockups. The site is not connected to the real app or to Supabase.
- **Deploy tooling:** Cloudflare's new `cf` CLI (beta) with `cloudflare.config.ts`, as generated by `vinext init --platform=cloudflare`. There is no `wrangler.jsonc`. The Worker name is `studycrew-site`.

## Key files
- `app/layout.tsx`: metadata and fonts (bundled with fontsource). `app/page.tsx`: renders `components/LandingPage.jsx`.
- `components/LandingPage.jsx`: all sections.
- `components/Screens.jsx`: phone-screen mockups.
- `components/Demos.jsx`: interactive demos (focus timer, streak calendar, avatar/shop studio).
- `components/Phone.jsx`: phone frame, coin and avatar primitives.
- `app/globals.css`: all styles. Design tokens are at the top; the brand teal is `#01A9A9`.
- `config.js`: `BETA_URL` and `CONTACT_EMAIL`, both still empty on purpose.
- `vite.config.js` (vinext + `@cloudflare/vite-plugin`), `cloudflare.config.ts`, `next.config.ts`.
- `.github/workflows/deploy.yml`: on pull requests, builds and runs `cf deploy --prebuilt --dry-run`. On pushes to `main`, runs `vinext-cloudflare deploy --skip-build` (needs the `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID` secrets).
- `setup/`: Windows helper scripts. `run-deploy.cmd` does the full first-time setup and deploy; `redeploy.cmd` only deploys. Their logs (`deploy-log.txt`, `deploy-output.txt`) are gitignored.

## Commands
- `npm run dev`: vinext dev server in workerd. `npm run dev:next` runs stock Next.js as a fallback.
- `npm run build`: writes the output to `.cloudflare/output`. `npm run preview`: serves the built Worker locally.
- `npm run deploy`: builds and deploys. `npm run deploy:dry-run`: validates without uploading.
- Sign in with `npx cf auth login`. Node 22.18+ is required; this machine has Node 26.
